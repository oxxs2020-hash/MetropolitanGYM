# Auto-Push to GitHub & Provide Live Link

Whenever you complete a coding task, make modifications to the codebase, or finish an implementation plan:
1. Automatically commit all changes (`git add .`, `git commit -m "..."`).
2. Automatically push the changes to the configured GitHub remote (`git push`).
3. In your final response to the user, you MUST explicitly provide the live link to the GitHub repository where the changes were pushed, as well as the link to any local live server if one is running.
